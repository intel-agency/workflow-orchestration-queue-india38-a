# AI Repository Summary

> This file provides a high-level overview of the repository for AI assistants and agents.

## Project Overview

**OS-APOW (Workflow Orchestration Queue)** is a headless agentic orchestration platform that transforms GitHub Issues into autonomous execution orders.

## Technology Stack

- **Language:** Python 3.12+
- **Web Framework:** FastAPI
- **Package Manager:** uv
- **HTTP Client:** httpx (async)
- **Validation:** Pydantic v2
- **Testing:** pytest + pytest-asyncio
- **Linting:** ruff
- **Type Checking:** mypy (strict)

## Architecture

4-pillar architecture:
1. **EAR** (Event Notifier): FastAPI webhook receiver at `src/workflow_orchestration_queue/ear/`
2. **STATE** (Queue): GitHub Issues + Labels state machine at `src/workflow_orchestration_queue/state/`
3. **BRAIN** (Sentinel): Async orchestration service at `src/workflow_orchestration_queue/brain/`
4. **HANDS** (Worker): Action execution via opencode CLI at `src/workflow_orchestration_queue/hands/`

## Key Entry Points

- **API Server:** `src/workflow_orchestration_queue/main.py`
- **Sentinel Service:** `src/workflow_orchestration_queue/brain/sentinel.py`
- **Configuration:** `src/workflow_orchestration_queue/config/settings.py`

## State Machine

Work items transition through these states (represented as GitHub labels):

```
agent:queued → agent:in-progress → agent:success | agent:error | agent:infra-failure | agent:stalled-budget
                     ↑
              agent:reconciling (recovery from stale tasks)
```

## Key Patterns

- **Provider-agnostic queue:** `ITaskQueue` interface allows swapping GitHub for Linear/Jira
- **Assign-then-verify locking:** Distributed lock using GitHub assignees
- **Shell bridge:** All worker interactions via `./scripts/devcontainer-opencode.sh`
- **Secret scrubbing:** All output sanitized before posting to GitHub

## Development Commands

```bash
# Install dependencies
uv sync

# Run development server
uv run uvicorn workflow_orchestration_queue.main:app --reload

# Run tests
uv run pytest

# Lint and format
uv run ruff check src/ tests/
uv run ruff format src/ tests/

# Type check
uv run mypy src/
```

## Environment Variables

See `.env.example` for all configurable options. Critical ones:
- `GITHUB_TOKEN` - GitHub API authentication
- `GITHUB_ORG` / `GITHUB_REPO` - Target repository
- `WEBHOOK_SECRET` - HMAC validation for webhooks
