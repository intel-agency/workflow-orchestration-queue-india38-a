## BuildInstructions

### Prerequisites
- Python 3.12+ (via uv)
- Docker (for devcontainer)
- PowerShell Core (pwsh) for validation scripts

### Bootstrap
```bash
# Install Python dependencies
uv sync

# Install dev tools (linters, scanners)
pwsh -NoProfile -File ./scripts/install-dev-tools.ps1
```

### Development Server
```bash
# Run FastAPI server with hot reload
uv run uvicorn workflow_orchestration_queue.main:app --reload

# Run in Docker
docker compose up -d
```

### Validation (REQUIRED before commits)
```bash
# Run ALL checks (lint, scan, test) — LOCAL DEFAULT
pwsh -NoProfile -File ./scripts/validate.ps1 -All

# Individual checks (mirrors CI jobs)
pwsh -NoProfile -File ./scripts/validate.ps1 -Lint    # actionlint, hadolint, shellcheck, PSScriptAnalyzer
pwsh -NoProfile -File ./scripts/validate.ps1 -Scan    # gitleaks secret detection
pwsh -NoProfile -File ./scripts/validate.ps1 -Test    # Pester + bash tests

# Devcontainer-specific tests
bash test/test-devcontainer-tools.sh
bash test/test-prompt-assembly.sh
```

### Code Quality
```bash
uv run ruff check src/ tests/      # Lint
uv run ruff format src/ tests/     # Format
uv run mypy src/                   # Type check (strict)
```

### Tests
```bash
uv run pytest                      # Python unit tests
bash test/test-devcontainer-build.sh
bash test/test-devcontainer-tools.sh
bash test/test-prompt-assembly.sh
```

## ProjectLayout

### Architecture (4-Pillar)

| Pillar | Component | Location | Purpose |
|--------|-----------|----------|---------|
| **EAR** | Notifier | `src/workflow_orchestration_queue/ear/` | FastAPI webhook receiver |
| **STATE** | Queue | `src/workflow_orchestration_queue/state/` | GitHub Issues + Labels state machine |
| **BRAIN** | Sentinel | `src/workflow_orchestration_queue/brain/` | Async orchestration service |
| **HANDS** | Worker | `src/workflow_orchestration_queue/hands/` | Action execution via opencode CLI |

### State Machine (GitHub Labels)
```
agent:queued → agent:in-progress → agent:success | agent:error | agent:infra-failure | agent:stalled-budget
                     ↑
              agent:reconciling (recovery from stale tasks)
```

### Key Files

| Path | Purpose |
|------|---------|
| `pyproject.toml` | Project config, dependencies, tool settings |
| `src/workflow_orchestration_queue/main.py` | FastAPI entry point |
| `src/workflow_orchestration_queue/config/settings.py` | Configuration management |
| `src/workflow_orchestration_queue/state/models/work_item.py` | Unified data model |
| `src/workflow_orchestration_queue/state/store/github_queue.py` | Queue implementation |
| `AGENTS.md` | Agent instructions (single source of truth) |
| `opencode.json` | opencode CLI config with MCP servers |

### CI/CD Workflows

| Workflow | Trigger | Purpose |
|----------|---------|---------|
| `validate.yml` | push to main, PRs | Lint, scan, test, devcontainer build |
| `publish-docker.yml` | push to main (Dockerfile changes) | Build/push base image to GHCR |
| `prebuild-devcontainer.yml` | workflow_run (after publish-docker) | Layer devcontainer Features |
| `orchestrator-agent.yml` | issues, workflow_dispatch | Run AI orchestrator in devcontainer |

## Coding Conventions

- Keep changes minimal and targeted
- Do not hardcode secrets/tokens
- Preserve `__EVENT_DATA__` placeholder in `.github/workflows/prompts/orchestrator-agent-prompt.md`
- Pin action versions by SHA in workflow files
- Never add duplicate top-level `name:`, `on:`, or `jobs:` keys in workflow YAML
- Run `./scripts/validate.ps1 -All` before committing non-trivial changes
- Monitor CI after push: `gh run list --limit 5`, `gh run watch <id>`

## Template Context

This is a **GitHub template repository**. New projects are created via `nam20485/workflow-launch2` scripts:
1. `create-repo-from-slug.ps1` → creates repo from template
2. Seeds `plan_docs/`, replaces placeholders (`workflow-orchestration-queue-india38-a` → new repo name)
3. `validate` → `publish-docker` → `prebuild-devcontainer` workflow chain builds the devcontainer image
